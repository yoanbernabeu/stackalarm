# Contributing

stackalarm takes contributions **through issues only**. Pull requests are closed automatically, whatever their quality: it keeps the project small, reviewable and consistent.

- **A new source** (the most useful contribution): open a [New source](../../issues/new?template=new-source.yml) issue. The form asks for exactly what `sources/<id>.yaml` needs.
- **A bug**: open a [Bug report](../../issues/new?template=bug.yml).
- **An idea** for the CLI or the skill: open an [Idea](../../issues/new?template=idea.yml).

## What makes a good source

- Official: the project itself, its security team, or a CERT.
- Machine-readable: an RSS or Atom feed, or a GitHub repository that publishes security advisories.
- Early: a source that announces security releases ahead (a heads-up) is worth more than one more advisory mirror.
- Focused: when a feed mixes security with other news, give keywords so only security entries are kept.
